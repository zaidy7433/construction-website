# 🏗️ Construction Website

### 🏠 Building Dreams, Creating Futures

A modern and attractive construction website built using HTML and CSS. This project showcases construction services, featured projects, a contact form, and a professional design with animations.

## 🌐 Live Demo

🔗 **[Visit Construction Website](https://zaidy7433.github.io/construction-website/)**

## ✨ Features

- 🏗️ Modern construction website design
- 🎨 Attractive colors and styling
- 🧭 Navigation bar with logo
- 🖼️ Hero section with background image
- 🛠️ Construction services section
- 📸 Feature cards with images
- 📩 Contact form UI
- 🎬 Smooth CSS animations
- 🖱️ Hover effects
- 📱 Responsive design using CSS media queries
- 🦶 Simple and clean footer

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations
- Flexbox
- Media Queries
- Google Fonts
- Unsplash Images
